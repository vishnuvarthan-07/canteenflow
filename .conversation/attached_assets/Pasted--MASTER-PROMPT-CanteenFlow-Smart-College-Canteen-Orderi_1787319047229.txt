# 🚀 MASTER PROMPT: CanteenFlow - Smart College Canteen Ordering System

## 🎯 PRIMARY OBJECTIVE

Build a **production-ready frontend prototype** for **CanteenFlow**, a modern college canteen ordering platform that enables students to browse food, place orders, select pickup times, and track their orders - all without calling or visiting the canteen.

---

## 👤 USER PERSONAS

### Primary Persona: The Hostel Student
- **Name:** Vishnu (Typical User)
- **Age:** 18-22
- **Pain Points:** 
  - Long queues during lunch/dinner hours
  - Phone lines always busy
  - Wastes 20-30 minutes waiting in line
  - Limited time between classes
  - Craves quick, reliable food ordering
- **Goals:**
  - Order food in under 1 minute
  - Know exactly when food will be ready
  - Skip the queue entirely
  - Get notifications when food is ready
- **Tech Comfort:** High - uses mobile apps daily

### Secondary Persona: Canteen Owner/Admin
- **Name:** Mr. Sharma
- **Pain Points:**
  - Manual order management
  - No visibility into peak hours
  - Overwhelmed during rush times
  - Difficulty managing inventory
  - Can't analyze sales trends
- **Goals:**
  - Streamline order management
  - Know what's selling best
  - Manage time slots efficiently
  - Reduce chaos during peak hours
  - Improve student satisfaction

### Custom Hooks

#### useCart
```typescript
const useCart = () => {
  const [items, setItems] = useState<CartItem[]>([]);
  
  const addItem = useCallback((food: FoodItem) => {
    setItems(prev => {
      const existing = prev.find(item => item.id === food.id);
      if (existing) {
        return prev.map(item => 
          item.id === food.id 
            ? { ...item, quantity: item.quantity + 1 }
            : item
        );
      }
      return [...prev, { ...food, quantity: 1 }];
    });
  }, []);

  // ... other methods

  return { items, addItem, removeItem, updateQuantity, clearCart, totalItems, subtotal, total };
};
```
